# MoneyMap — Personal Finance for Teens

## Files
- `index.html` — homepage
- 15 HTML pages total, each with its own topic
- `styles.css` — all visual styling (external CSS)

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `moneymap`.
2. Upload all `.html` files and `styles.css` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. Your URL will look like `https://amansceronald-bot.github.io/moneymap/`.
7. Open the URL and test several navigation links. Paste the real live URL into your class submission and documentation.

Replace `amansceronald-bot` with your GitHub username. Do not submit the example URL before confirming it works.
